# 💬 Web Chat

一个基于 Web 的实时聊天系统，用于学习网络通信与客户端-服务器架构，实现基础的在线聊天功能。


## 🚀 项目简介

本项目实现了一个简单的在线聊天系统，支持用户之间的实时通信。通过该项目，探索了 Web 应用开发流程以及网络通信机制（客户端与服务器之间的数据交互）。

项目主要用于练习：
高性能网络编程（muduo）
- 网络编程基础
- Web 前后端交互
- 系统设计与工程实践
- C++
- 网络通信 Socket
- josn用来通信
- Git
- CMake
- mysql

- 实现基础的用户聊天功能
- 支持消息的实时发送与接收
- 简单的前端聊天界面
- 客户端与服务器通信机制

- ./chatsever启动本地程序
- ./chatClient连接服务器
